## ✨ Fonctionnalités

- **Toutes les techniques du serveur**, classées par élément (Katon, Suiton, Jinton…), avec recherche instantanée.
- **Modifications en direct** : chaque valeur changée est appliquée en jeu en moins d'une seconde.
- **Journal complet** : qui a modifié quoi, quand, depuis le jeu ou l'application, avec un bouton « Annuler ».
- **Travail en équipe** : voyez qui est connecté, recevez une notification quand un membre modifie une valeur.
- **Comptes individuels** : chaque modification est signée au nom de son auteur.
- **Mises à jour automatiques** : l'application se met à jour toute seule.

## 📥 Installation

1. Téléchargez **`KETSU-Equilibrage-Setup.exe`** depuis la [dernière version](https://github.com/sinay88213-ui/ketsu-equilibrage-app/releases/latest).
2. Lancez-le (si Windows affiche « Windows a protégé votre ordinateur » : *Informations complémentaires* → *Exécuter quand même*).
3. Connectez-vous avec le pseudo et le mot de passe fournis par un administrateur.

## ⌨️ Raccourcis

| Action | Raccourci |
|---|---|
| Rechercher | `Ctrl` + `F` |
| Techniques · Journal · Équipe · Réglages | `Ctrl` + `1` à `4` |
| Ajuster une valeur | `↑` `↓` (`Maj` ×10, `Ctrl` ÷10) |
| Valider · Annuler la saisie | `Entrée` · `Échap` |
